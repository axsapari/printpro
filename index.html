PrintManager Pro

v2 — Konfigurasi Supabase

Hubungkan ke Supabase
Masukkan URL dan Anon Key dari project Supabase Anda.
💡 Buka supabase.com → Project → Settings → API
Salin Project URL dan anon/public key.
Setup Database
Buka SQL Editor di Supabase, jalankan SQL di bawah ini, lalu klik Verifikasi.

        
      

      

      

        
        
      

    

    

      
Siapkan Akun Pengguna

      
Akun dibuat langsung di Supabase (bukan lewat aplikasi) supaya password tidak tersimpan di kode.

      
📌 Buka Supabase → Authentication → Users → Add user, buat akun berikut dengan password buatan Anda sendiri (centang Auto Confirm User). Setelah itu jalankan kembali bagian 5. BERI PERAN pada SQL di langkah sebelumnya.

      

      
⚠ Matikan pendaftaran publik: Authentication → Sign In / Providers → nonaktifkan Allow new users to sign up.
